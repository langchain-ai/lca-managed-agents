# Example brand: Northbeam Coffee

A complete example of a brand, for reference while you write your own in Lab 1.

- `brand.json`: the brand as data, which code checks every design against
- `brand-guidelines.md`: the same brand as a skill, which tells the agent how to design for it

This folder isn't part of your agent. Your agent's brand lives in `brand.json`
and `skills/brand-guidelines/SKILL.md`.
